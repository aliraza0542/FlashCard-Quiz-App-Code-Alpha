# Flashcard Quiz App

A simple and interactive Android Flashcard Quiz Application built using **Java, XML, and Android Studio**. The app helps users study and memorize information through customizable flashcards and quiz-based learning.

## Features

### Flashcards

* View flashcards with questions and answers.
* Flip cards to reveal answers.
* Navigate through flashcards easily.
* Organize study materials into topics and folders.

### Quiz Mode

* Test your knowledge using quiz mode.
* Multiple-choice questions.
* Instant feedback on answers.
* Score tracking and performance evaluation.

### Flashcard Management

* Create new flashcards.
* Edit existing flashcards.
* Delete flashcards.
* Manage topics and study sets.

### User Features

* User Registration and Login.
* Profile Management.
* Personalized learning experience.

### Study Tools

* Topic organization.
* Folder management.
* Study progress tracking.
* Quiz result summaries.

## Screenshots

### Welcome Screen

* Application splash screen with "Let's Play" button.

### Flashcard Screen

### Flashcard Library

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YourUsername/FlashcardQuizApp.git
```

2. Open the project in Android Studio.

3. Sync Gradle files.

4. Run the application on an Android emulator or physical device.

## How to Use

1. Create an account or log in.
2. Create topics and flashcards.
3. Organize flashcards into folders.
4. Study using flashcard mode.
5. Test yourself using quiz mode.
6. Review results and improve your performance.
